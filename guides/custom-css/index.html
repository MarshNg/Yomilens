Custom CSS

Setup & usage

  1. 1

    In a build that includes Custom CSS, open Settings → General → Custom CSS.

  2. 2

    Use Insert Example to replace the editor with either a theme starter or a colorful stress test, then edit the YomiLens selectors you need.

  3. 3

    Click Preview before saving. You can save, load, and delete your own named presets. Yomitan CSS is not directly compatible; this field accepts CSS, not JavaScript.
